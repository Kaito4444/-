# ABYSS RUN 🔥 — 死にゲー・鬼畜プラットフォーマー

Swift + SpriteKit 製の、横スクロール死にゲーiOSアプリ（1面完成品）。  
外部アセット不要。全グラフィックをコードで描画。横画面専用。

---

## ファイル構成

```
AbyssRun/
├── AbyssRun.xcodeproj/project.pbxproj
└── AbyssRun/
    ├── AppDelegate.swift        アプリエントリー
    ├── GameViewController.swift SKView、横画面設定
    ├── Constants.swift          物理定数・カラーパレット・ゲーム定数
    ├── TextureFactory.swift     ピクセルアートテクスチャ生成
    ├── TitleScene.swift         タイトル画面
    ├── GameScene.swift          メインゲームシーン（状態管理・物理コールバック）
    ├── Player.swift             プレイヤーノード・入力処理・慣性
    ├── Enemy.swift              敵ノード・AIパトロール
    ├── BlockNode.swift          ブロック種別・崩れ・消滅ロジック
    ├── StageBuilder.swift       セクションテンプレート定義・ランダム配置
    ├── HUDNode.swift            タイマー・死亡数表示・仮想ボタン
    └── Info.plist
```

---

## Xcode でのビルド手順

1. `AbyssRun.xcodeproj` を Xcode 15+ で開く
2. Targets → AbyssRun → Signing & Capabilities → 自分のチームを選択
3. Bundle Identifier を変更（例: `com.yourname.AbyssRun`）
4. iPhone 実機またはシミュレーター（横向き）で Run

**必要環境:** Xcode 15以上 / iOS 16.0以上 / Swift 5.9以上

## 操作方法

| コントロール | 機能 |
|---|---|
| **◀ ▶** | 左右移動（慣性付き） |
| **JUMP** | ジャンプ（長押しで高くなる、空中制御あり） |
| 敵の**上から踏む** | 敵を倒してバウンド |
| 敵に**横から触れる** | 即死 |

## ゲームシステム

| 要素 | 仕様 |
|---|---|
| **タイマー** | 90秒 制限 |
| **死亡** | スタートからリスタート（残機なし） |
| **死亡カウント** | 画面右上に表示 |
| **ゲームオーバー** | 30回死亡で表示（慈悲）|
| **クリア** | クリアタイム＋死亡数を表示 |

## ブロック種別

| ブロック | 見た目 | 効果 |
|---|---|---|
| **グラウンド** | 濃いグレー・石畳模様 | 通常の足場 |
| **ストーン** | 暗いグレー・クロス模様 | 通常の足場（壁/高台） |
| **クランブル** | 茶色・ひびわれ | 乗ると0.9秒後に崩れる |
| **バニッシュ** | 紫・点滅 | 1.5秒表示→1秒消滅を繰り返す |
| **スパイク** | 赤いトゲ | 触れると即死 |
| **移動プラット** | 緑 | 水平/垂直に往復する足場 |
| **ゴール** | 金色 | 触れるとクリア |

## 難易度設計の意図

```
§Tutorial    落とし穴と最初の敵でチュートリアル
§ランダム×5  毎回順番が変わる5種の難関セクション
  ├ ギャップ+スパイク    ジャンプ精度を問う
  ├ 水平移動プラット     タイミングを問う
  ├ 垂直移動プラット     上下タイミングを問う（最難）
  ├ クランブルブリッジ   急いで渡らないと崩れる
  ├ バニッシュ          消えるタイミングを覚える必要
  └ 狭い足場+敵         踏み外しor踏み勝負
§ファイナル  全要素の複合・最高難易度
§ゴール      逃げ切り
```

## 今後2面以降を追加する場合

1. `StageBuilder.swift` に新しい `SectionDef` を追加
2. `randomPool` 配列に追加（自動でシャッフル対象になる）
3. 固定セクション（序盤・終盤）は `build()` 内の配列を編集
4. 新しいブロック種別が必要なら `BlockType` enum と `BlockNode.make()` を拡張
5. 新しい敵を追加する場合は `EnemyKind` を `Enemy.swift` で拡張
