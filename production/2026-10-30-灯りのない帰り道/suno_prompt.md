# 灯りのない帰り道 / Suno プロンプト(案C)

出典: plans/2026-10-30.md 案C(優先度: 中〜低、任意)。OP型(案A)・青春ポップ型(案B)と対比する検証枠。需要の裏付けはない。

## 位置づけ(重要)
- 案A・Bの生成と試聴が常に優先。案Cは、A・Bが基準未達、または人に余裕がある場合のみ生成する。
- ダウンロードは試聴後の有望曲のみ(Suno月間上限の二次情報に備える)。
- 最終候補は最大1曲。2曲目以降は作らない。

## タイトルについて(人の確認が必要)
- 仮タイトル案3つ(「最後のページ」「静かな約束」「灯りのない帰り道」)から「灯りのない帰り道」を選択。理由: 3案の中で語の組み合わせが最も具体的で、歌詞の情景(街灯の消えた道)と対応させやすい。
- ただし一般的な語の組み合わせのため、同名曲が存在する可能性が高い。最終決定前に、人が配信サービス・検索サイトで同名曲を確認すること。被る場合は固有の語を足して変更する(例: 場面や小物を表す語を付加)。変更時は本ディレクトリ名・歌詞・ジャケ文字も合わせる。

## Style プロンプト(英語・ジャンル用語のみ)
```
emotional piano ballad, J-pop ballad, slow tempo, lyrical grand piano lead, warm string section, soft cello, gentle sustained pad, minimal brushed drums entering at second verse, intimate expressive female vocal, restrained verse, emotionally opening chorus, cinematic build, quiet fading ending, wistful and tender, polished modern production
```

## テンポ・キー
- BPM: 66〜76(Style欄に "70 bpm" を追記可)。ミドル〜スロー。
- キー: 出力次第。短調寄りの導入からサビで光が差す展開を想定(例: D minor→F major 方向。固定しない)。
- 目標曲尺: 3〜4分(2.5分未満は不採用)

## 構成
Intro(ピアノのみ) → Verse1(ピアノ+ボーカル、静か) → Pre-Chorus(弦が入る) → Chorus(感情が開く) → Verse2(ブラシドラム追加) → Pre-Chorus → Chorus → Bridge(ピアノと声だけに戻り、盛り上げ) → Last Chorus(弦を厚く) → Outro(ピアノのみで静かに閉じる)

## Exclude(Negative prompt)
```
lo-fi, chillhop, EDM drop, rap, screaming, heavy distortion, aggressive drums, upbeat, dance beat, instrumental only, mumbling vocals, vinyl crackle
```

## オリジナル性の運用(plans/2026-10-30.md 方針1〜9に対応)
- Style欄にはジャンル・楽器・テンポ・雰囲気の一般語のみ。実在アーティスト・作品・キャラ・曲名は入れない。
- Sunoのカバー/リミックス機能、他人の音源のアップロード入力は使わない。
- 出力は原則そのまま採用か不採用か。微差バージョンの量産はしない。
- AI検出回避を目的とした音声加工はしない。配信時のAI開示欄には正直に記入する。
- 記録を残す(人): 元の生成物、この指示書、生成日、Suno有料プラン加入期間。

## 生成バリエーション数の目安
- 初回: 2回生成(1回2曲=4曲)を試聴。案Cは任意枠のため少なめ。
- 不満点が歌詞の長さ/発音なら、歌詞を微修正して最大1〜2回まで追加。
- 合計でも最大6曲程度まで。ダウンロードは有望曲のみ。最終候補は最大1曲。

## 試聴選定チェックリスト(人が試聴して選ぶ)
品質
- [ ] 曲尺が2.5分以上ある
- [ ] 歌詞の脱落・誤読・意味不明な反復がない
- [ ] 日本語の発音が自然(サビの「灯り」「帰り道」、Verse1の「改札」等)
- [ ] ボーカルが不自然でなく、声質が途中で変わらない
- [ ] ピアノと弦が主体で、サビで感情が開く構成になっている
- [ ] ラストが静かに自然に閉じる(唐突な切れ方でない)
- [ ] Lo-fi寄り・BGM的になっていない
- [ ] 案A・案Bと明確に違う曲調(重複感がない)

類似チェック(必須)
- [ ] 「聴いたことがある」と感じる旋律・コード進行・イントロがない(感じたら候補から外す。耳での確認であり完全な保証ではない)
- [ ] サビの特徴的なフレーズ(例: 「灯りのない帰り道」「ひとつだけ点いていた」)を検索し、既存歌詞との一致がない
- [ ] タイトルの同名曲を配信サービス・検索で確認した(被る場合は固有の語を足して変更)
- [ ] 他人の音源を入力に使っていない

最終判定
- [ ] 「週の候補にして良い」か「見送り」かを記録(今週のアップロードは最大1曲。A・Bとの比較も)
- [ ] 採用する場合、Suno有料プラン加入中に生成・ダウンロードしたことを確認
