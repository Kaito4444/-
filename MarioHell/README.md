# Mario Hell 🔥 — 激ムズiOSマリオ

ファミコン版スーパーマリオブラザーズ風の、**鬼難しい**1面限定iOSゲームです。  
SpriteKit で実装されており、すべてのグラフィックはコードで描画します（アセット不要）。

---

## 操作方法

| ボタン | 機能 |
|--------|------|
| **◀ ▶** | 左右移動 |
| **B**   | 走る（ジャンプ距離も伸びる）|
| **A**   | ジャンプ（長押しで高く飛べる）|
| **A + B 同時** | 走り高跳び（推奨）|

---

## 難しさの理由

| 要素 | 詳細 |
|------|------|
| **制限時間 75 秒** | ゆっくり進む余裕なし |
| **強い重力** | 落下が速い、ジャンプの調整が難しい |
| **1タイル幅の足場** | セクション9は幅32px の超狭いプラットフォーム |
| **移動足場** | すべりやすい（摩擦0）、しかも高速移動 |
| **縦移動足場** | 上下する足場、タイミング必須 |
| **ハンマーブロス** | 1.2秒ごとに3本ハンマーを投げる |
| **バレットビル** | 2つの発射台が2.5秒ごとに発射 |
| **パックンフラワー** | 0.5秒しかない安全窓 |
| **ファイヤーバー** | プラットフォームの大半を覆う |
| **チェックポイントなし** | ミスしたら最初からやり直し |
| **敵の多さ** | ゴンボー・ノコノコ・ハンマーブロスが密集 |

## Xcodeでの開き方

1. Xcode を開く
2. `File > Open` → このフォルダ内の `MarioHell.xcodeproj` を選択
3. Bundle Identifier を自分のものに変更（`com.example.MarioHell` → 自分のIDに）
4. Signing & Capabilities で自分のチームを選択
5. iPhone 実機またはシミュレーターで Run

### 必要環境
- Xcode 15 以上
- iOS 16.0 以上
- Swift 5.9 以上

## ゲームの流れ

```
§1 開幕死のトラップ     → 狭い足場と即死の穴
§2 移動足場地獄         → 巨大な穴の上の高速移動足場
§3 ハンマーブロス       → 2体が待ち構える
§4 パックンフラワー地帯 → 3本のパイプ、ほぼ隙間なし
§5 高台 + ファイヤーバー→ 足場が狭くて回転する炎
§6 縦移動足場           → 3つの上下する足場を乗り継ぐ
§7 敵の殲滅地帯         → 6体の敵 + バレットビル×2
§8 階段迷路             → 登り降りにノコノコが待つ
§9 最終死廊下           → 1タイル幅の足場 × 5 + ハンマーブロス
🏁 ゴール               → フラッグポールに触れたらクリア
```
